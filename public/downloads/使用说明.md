# Soundfolio · Spotify 收藏导出与分析

## 1. 准备导出文件

原脚本生成的 Excel 可以直接导入，无需修改。网站支持 `.xlsx`、UTF-8 `.csv` / `.tsv`、`.json`，最多 20 MB / 50,000 条歌曲记录。旧版 `.xls` 请另存为 `.xlsx`。

如果你还没有文件，可运行本站提供的安全版 Python 脚本。它保留原脚本的六个字段，并尽可能附加毫秒时长、发行日期、explicit、专辑类型、编号、Spotify ID；热度字段仅在 API 实际返回时导出。

1. 在自己的电脑安装 Python 3.10 或更新版本。
2. 安装依赖：

```sh
python3 -m pip install spotipy pandas openpyxl
```

3. 在 [Spotify 开发者后台](https://developer.spotify.com/dashboard) 创建或选择自己的应用。将应用的 Redirect URI 设为 `http://127.0.0.1:8888/callback`。账号、开发模式和 API 使用资格以 Spotify 当前要求为准；网站文件分析本身不需要 Spotify 授权。
4. 在你本地终端设置环境变量。**不要把真实密钥发给别人、提交到仓库或写进公开网站。** 下面是 macOS / Linux 写法，占位内容请在你自己电脑上替换：

```sh
export SPOTIPY_CLIENT_ID='你的 Client ID'
export SPOTIPY_CLIENT_SECRET='你的 Client Secret'
export SPOTIPY_REDIRECT_URI='http://127.0.0.1:8888/callback'
python3 export_spotify_liked_songs.py
```

Windows PowerShell 用 `$env:SPOTIPY_CLIENT_ID='…'` 等语法设置同名变量，然后运行脚本。

首次运行需在浏览器登录授权。脚本将令牌缓存在本地 `.spotify_cache`，请妥善保管，勿分享。默认输出 `spotify_liked_songs.xlsx`。文件已存在时会退出，可通过 `--output 新文件名.xlsx` 指定新路径。也支持 `--format json` 或 `--format csv`。

安全版脚本替换了用户原文件中的硬编码凭证，网站不提供含密钥的旧脚本副本。如果旧密钥曾被公开，请在 Spotify 后台轮换。原文件在电脑上保持不变。

## 2. 导入分析

打开 Soundfolio →「导入我的数据」→ 选择或拖入文件。网站在浏览器内存中处理；不上传、不写入浏览器持久存储，刷新后恢复演示数据。

- 支持原字段：歌曲名、艺人、专辑、时长、添加时间、链接。
- 歌曲名为唯一必需字段。支持 `name` / `track_name` / `title`、`artists` / `artist`、`album`、`duration_ms` / `duration_seconds`、`added_at` 等英文列名。
- 数值时长默认单位为秒；`duration_ms` 单位为毫秒；文本时长支持 `m:ss` 和 `h:mm:ss`，也兼容 Excel 时间小数。
- 日期支持 `YYYY-MM-DD`、ISO 时间戳、Excel 日期单元格。只有发行年份的 `release_date` 也可用于发行年份分析。
- JSON 可以是数组或 `{ "items": [...] }` / `{ "tracks": [...] }` / `{ "songs": [...] }`，支持 Spotify `items[].track` 结构。
- Excel 读取名为「喜欢的音乐」的工作表；否则使用第一张工作表。第一行必须为列名。
- 艺人字符串按逗号 / 分号拆分。艺人名字本身含逗号时，请优先使用 JSON 的 `artists` 数组。

## 3. 指标与下载

歌手比较默认门槛为 **收藏 ≥3 首**，可改为 1 / 4 / 5 / 10 / 20 首。可按收藏数量、累计时长、平均时长、专辑数量排行，同时比较最多 6 位歌手。

全部合作艺人模式：每首合作曲分别计入所有参与艺人，所以歌手总数 / 时长之和可能大于曲库总数 / 时长。第一位艺人模式则只计入首位艺人。未标注艺人的记录不算作某位艺人。

缺失或无效时长不参与平均值；缺失日期不参与时间线。疑似重复不会自动删除；以 Spotify 链接（去除查询参数）或歌曲名+艺人+专辑识别重复。每条有效歌曲行仍计入总收藏数。

「原始文件」下载用户导入文件的原始字节；演示模式下载模拟原始 CSV。分析导出包括完整 JSON 报告、当前收藏时间范围 CSV、符合当前门槛的歌手 CSV；曲库右侧另提供搜索与筛选后的 CSV。

分析报告是收藏画像，**不是实际播放记录**。累计时长是每首歌曲播放一次的时长之和；没有播放历史就不能推断播放次数和真实收听时间。没有对应字段时，不推测流派、BPM 或情绪。热度如存在，是导出时间的快照。所有原始列（包括未识别的额外字段）都会显示有效值、不同值和摘要。

演示数据为人工构造，歌曲标题、时长与收藏日期仅用于展示；不是任何人的实际数据。
